🏗️ POC - Application Layer

📚 Qu'est-ce que l'Application Layer ?

La couche Application orchestre la logique métier du Domain Layer. Elle contient les Use Cases (cas d'utilisation) et les Services qui coordonnent les entités du domaine.

  • Use Cases: StartGameUseCase, ExecuteActionUseCase
  • Services: EventBus, TurnManager
  • DTOs: Conversion entités ↔ objets simples
